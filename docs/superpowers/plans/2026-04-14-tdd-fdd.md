# TDD + FDD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Verify, fix, and document Type-Driven (TDD) and Feature-Driven (FDD) test suites across all four services, and create an FDD features reference document.

**Architecture:** Tests already exist across menu-service, auth-service, warehouse-service (all FastAPI/async with pytest-asyncio + SQLite in-memory) and order-service (Flask/sync). The main deliverable is the FDD features document plus validation that all tests run correctly.

**Tech Stack:** pytest, pytest-asyncio, pytest-cov, httpx/ASGITransport (FastAPI services), Flask test client (order-service), aiosqlite (in-memory DB), Pydantic v2, mypy strict.

---

## Test Layout (all services follow this structure)

```
tests/
├── conftest.py          # async engine + session + HTTP client fixtures
├── types/               # TDD layer — Pydantic schema tests, no DB/HTTP
│   └── test_*.py
└── features/            # FDD layer — HTTP integration tests per feature
    └── test_*.py
```
